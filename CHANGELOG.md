# Изменения

## cli-snapshot-response-fix — 21.10.2026

На основе предоставленного main добавлен локальный адаптер обработки boolean false
в canonical_modules CLI 0.2.0. Полный снимок читается повторно без повторного push;
обязательны та же ревизия, текст всех модулей и совпадение manifest. Ошибки не скрываются.
Нет force, сброса БД или новых миграций. Предыдущее исправление схемы сохранено.
Добавлены 38 локальных тестов и инструкция по BotFather/CLI; CI PR проверяет новую функцию.
Живой сервер из сессии подготовки патча не изменялся.

## admin-releases-v1 — 19.10.2026

Добавлены серверная админка для двух Telegram ID, редактор режиссёров/фильмов, модерация,
JSON/CSV/TSV-импорт, экспорт, неизменяемые опубликованные каталоги и связки код + каталог.
Добавлены основной релиз, отдельный выбор для game, release/startapp-ссылки, административный
предпросмотр, архивирование с защитой активных указателей и история действий.

Добавлены optimistic-lock/CAS-сохранения, разделение локального прогресса по релизу/пользователю,
однократное недеструктивное копирование исходного сохранения, безопасное извлечение настоящей v06
из существующего checkout, неизменяемые пути и контроль hashes старых сборок.

Обновлены README, инструкции релиза, ручной publish.yml и check.yml. Публикация разделена на
backend, безопасную миграцию, облачный smoke-тест и frontend. Токен бота в код не добавляется;
прежний Serverless CLI token используется через существующий механизм CLI/GitHub Secrets.

Физическое хранилище MVP — один атомарно обновляемый документ SQLite, а не несколько отдельных
таблиц с незафиксированными промежуточными состояниями. Размер и история ограничены явно.

Это пакет обновления, а не полученный raw-снимок main. Включён сборщик полного объединённого
ZIP для запуска после наложения пакета на настоящую рабочую копию репозитория.

# Проверка состава объединённого main

## Установленные факты

Исходный ZIP: `redrooms-main (4).zip`.
Git archive comment: `1566f8c7ff0f89b8902340d7a25d555574282ed0`.
ZIP прошёл проверку CRC. Исследован именно присланный объединённый снимок,
не текущий удалённый GitHub и не восстановленная по памяти версия.

`ADMIN-TEST-ISOLATION-PATCH.json` в исходнике прямо указывает зависимость от
`redrooms-attempt-state-fix.zip`. Но его исходник `src/rr-game-v12.html`, запись
`v12-attempt-state` в обоих реестрах, готовые файлы и исправленный клиент отсутствуют.
При этом серверные `contest-service` и административные `admin-contest` полностью
совпадают с последним пакетом изоляции администраторов. Тесты этого пакета включают
сценарии предыдущего исправления состояния попыток.

Следовательно, main содержал смешанный комплект совместимых только при наличии
полной цепочки зависимостей файлов. По ZIP нельзя определить, на каком ручном шаге
или объединении пропала часть предыдущего пакета. Это не основание обвинять
пользователя в неправильной установке и не причина отключать проверки.

## Восстановление

Восстановлена точная ранее подготовленная сборка `v12-attempt-state`:
`/games/v12-attempt-state/37b9302c5ffc5a0b/index.html`.
Не изменены опубликованные файлы старых сборок. Исторические игровые ID и namespace
сохранений не переименованы. Правки `src/rr/domain.mjs`, `src/rr/service.mjs` и
`tgcloud/lib/rr/runtime.js` согласуют новую публикацию, обычный запуск и предпросмотр.
Серверная часть изоляции администраторов не заменена более старой версией.

Скопирован тестовый fixture старого клиента, необходимый для воспроизведения
ошибки до исправления. В тестовом сервере предпросмотр выбирает ту же v12, что
и в реальном runtime. Fixture и harness не попадают в публичную папку.

Все прежние `.test.mjs` сохранены побайтно: тесты не подгонялись под результат.
Повторная подготовка регенерирует публичные/серверные копии из согласованных
исходников. Полученные файлы включены в патч.

## Границы

Никаких операций с живой базой и Telegram в этой работе не выполнялось.
Отсутствие облачной ошибки после публикации необходимо проверить владельцам.
Новые механики и переработка интерфейса в патч не включены.

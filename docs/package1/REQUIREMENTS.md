# Соответствие согласованному пакету 1

| Требование | Реализация / проверка |
|---|---|
| ТЗ 0: минимальная интеграция | Сохранены подписка, текущая админка/каталоги, localStorage, 3D; новая v09 |
| 1: описания/финалы/статья | Контент отдельными записями, безопасное форматирование, server-side доступность |
| 1.4: дубликат | Полный серверный clone, включая годы/оригиналы/материалы, без игроков/попыток |
| 1.5: preview | Финальные тексты, статья; закрытый game preview черновика без записи результата |
| 2: две попытки | Резервации, CAS, идемпотентность, local outbox, сохранение до ACK |
| 3: серверный результат | Раскладка + журнал попыток размещения, 100/-75, признаки без автобана |
| 4: игроки/модерация | Настоящие Telegram-имена, поиск, история, исходные данные, решения с причиной |
| 5: цикл | Начало/срок/продление/закрытие/фиксация; архив играет вне зачёта |
| Уточнение пользователя | Final immutable навсегда, поздние решения только отдельной пометкой |
| 6.1–6.3 | Таблица попыток/лучших/мест, фильтры, доля завершения, ошибки по кассетам |
| 6.4 / новая оговорка | Только наблюдаемые запуски/параметр набора/изменение статуса подписки |
| 7: финалы | Серверный score, обе попытки, место, повтор, доступная статья и точная ссылка |
| 8: распространение | Обычный текстовый Telegram share URL; изображения/native/stories отложены |
| 9: посты | Шаблоны, данные/победители, top, правки/preview/copy; отправки в канал нет |
| 10: календарь | Простой список планов/сроков/статусов, без автопубликации |
| 11: данные | Версии логических записей rr_records, согласованный экспорт/restore и старый формат |
| Бэкап | JSON двум админам вручную/ежедневно/перед деплоем; checked restore, лимит 40 МиБ |
| Среды | Прежний stage workflow, отдельный production, ожидаемый username, разные секреты |
| 12: имена | User ID внутренний, username/name публичные; final хранит историческое имя |
| 13: исключённое | Не добавлены внешний сайт/домен/база, дуэли, автопостинг/баны |

Локальный браузерный тест использует настоящий код и SQLite, но синтетические SDK,
аккаунты, localStorage transport и навигацию. Приёмка на настоящем Telegram обязательна.

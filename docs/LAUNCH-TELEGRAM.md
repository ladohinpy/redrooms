# Красная комната — прямой запуск в Telegram (без zindone.ru)

**Цель:** опубликовать сохранённую игровую v06 с одной серверной функцией `checkAccess`, которая проверяет подписку игрока на тестовый канал **@redrooms_stage**. Без собственного сервера, SQLite, миграций и обработки `/start`.

**Важное различие:** `@redrooms_stage` — это КАНАЛ, на который надо подписаться. Бот, из которого запускается игра, — отдельный аккаунт с другим @username, созданный в BotFather. В настройках Mini App выбирайте **бота**, а не канал.

## Какой файл указывать в BotFather?

**Никакой файл в BotFather указывать не надо.** Нужен именно HTTPS-URL, который выдаёт Telegram Serverless после публикации:

`https://app<app_id>.tgcloud.ai/`

В ZIP `public/index.html` — главная страница. Файл `tgcloud.jsonc` указывает `static.source = "public"`, поэтому `index.html` будет автоматически открыт по корневому `/`. Серверные файлы `tgcloud/endpoints/checkAccess.js` и `tgcloud/lib/subscription.js` запускаются Telegram отдельно.

**Не подставляйте `https://t.me/redrooms_stage` вместо адреса игры:** это ссылка на канал, а не Mini App. **Не ставьте `zindone.ru`** — это старая публикация, не поддерживающая новый Serverless endpoint.

## 1. Подготовьте бота и канал в Telegram

1. Откройте `@BotFather` → `/mybots` → **нужный бот** → Serverless. Убедитесь, что Serverless включён (переключатель ON).
2. Откройте Telegram-канал **@redrooms_stage** → Управление / Администраторы → Добавить администратора → выберите **того же самого бота**. Дайте минимально допустимые Telegram права для добавления бота администратором. Публиковать посты ему не нужно; если Telegram позволяет назначить без лишних прав — не давайте лишних.
3. Убедитесь, что бот действительно числится администратором канала. Это обязательно для гарантированной проверки других пользователей через Bot API `getChatMember`.
4. Убедитесь, что Serverless настроен для тестового/целевого бота, а не другого действующего бота. Эта поставка **не создаёт handlers**, поэтому не настраивает `/start` и не перехватывает входящие сообщения.

## 2. Загрузите проект в GitHub (без локального терминала)

Репозиторий: https://github.com/ladohinpy/redrooms

1. Распакуйте новый ZIP, откройте репозиторий GitHub.
2. Если в нём уже есть файлы старой версии, обновите их из нового архива (удобно через GitHub Codespaces, который работает в браузере, либо через интерфейс загрузки файлов). Сохраните пути и каталоги; **не загружайте ZIP как одиночный файл**.
3. Убедитесь, что в `main` есть: `public/index.html`, `public/access-gate.js`, `tgcloud/endpoints/checkAccess.js`, `tgcloud/lib/subscription.js`, `tgcloud.jsonc`, `.github/workflows/publish.yml` и `.github/workflows/check.yml`.
4. Если используется PR, проверка `Check Mini App and Subscription` должна пройти, затем примите PR в `main`.

## 3. Подключите GitHub Actions к Telegram

1. В BotFather: **нужный бот → Serverless → CLI Access → Access token**.
2. Скопируйте токен только в GitHub (не отправляйте его в чат и не вставляйте в `index.html`, Git, issue или pull request).
3. Репозиторий GitHub → **Settings → Secrets and variables → Actions → New repository secret**.
4. Название: **`TGCLOUD_TOKEN`**. Значение: CLI access token из BotFather (обычно `app<id>:<secret>`).
5. В GitHub убедитесь, что Actions разрешены. Токен действителен именно для того бота, который должен размещать игру.

## 4. Опубликуйте Mini App + endpoint

1. Репозиторий → вкладка **Actions** → workflow **Publish Red Room Mini App + Subscription (manual)**.
2. Нажмите **Run workflow**, ветка `main`.
3. После успешного запуска раскройте задачу `publish` → шаг `Publish Mini App and subscription endpoint only`.
4. Найдите в логах итоговый URL вида **`https://app<app_id>.tgcloud.ai/`**. Сохраните его.
5. Workflow выполняет **только**:

   `npx tgcloud push tgcloud/lib/subscription.js tgcloud/endpoints/checkAccess.js public/`

   Он не запускает миграции, не публикует новые handlers, не удаляет чужие модули из Telegram Serverless. Не заменяйте это бездумно на полный `tgcloud push`, если бот уже имеет другую серверную логику. Не используйте `--force`.

## 5. Измените URL Mini App в BotFather (основной шаг ухода с Zindone)

1. В `@BotFather` выполните `/mybots` → выберите **того же бота** → **Bot Settings → Configure Mini App** (либо пункт **Main Mini App**, если в вашем интерфейсе так называется).
2. Если Mini App уже настроен на `zindone.ru`, выберите **Edit URL / Change URL** или эквивалентную команду. Если ещё не настроен — **Enable Mini App**.
3. В поле **URL** вставьте точный адрес из лога GitHub Actions: `https://app<app_id>.tgcloud.ai/`. Никаких `/public/index.html` и ссылок на канал здесь быть не должно.
4. Установите название приложения (например, «Красная комната») и подтвердите изменения.
5. **Если кнопка меню бота уже ведёт на zindone.ru, обязательно замените её URL**: **Bot Settings → Menu Button** (или `/setmenubutton`) → подпись «Играть» → тот же HTTPS-адрес Telegram Serverless. Если меню ранее не было — добавлять его необязательно, Main Mini App уже обеспечивает кнопку запуска.

После этого в профиле бота появится кнопка **Launch App / Запустить приложение**. Чтобы получить **прямую ссылку на запуск в Telegram**, возьмите *username самого бота* и составьте:

`https://t.me/<BOT_USERNAME>?startapp=redroom`

Здесь `<BOT_USERNAME>` — имя **бота**, а не `redrooms_stage`. Оно пока неизвестно, поэтому не надо выдумывать конечную ссылку. Когда будет имя бота, впишите точную ссылку в `PLAYER_CONFIG.telegramAppUrl` внутри `public/index.html`: тогда заработает кнопка «Поделиться игрой». После правки снова вручную выполните публикацию из GitHub Actions.

**Примечание:** собственная статическая ссылка `https://app<app_id>.tgcloud.ai/` может открываться и обычным браузером, но **проверенный вход в игру будет работать только через Telegram Mini App**: для вызова защищённого `checkAccess` нужны `initData`, подтверждённые Telegram. Это ожидаемо, а не ошибка сервера.

## 6. Быстрая проверка перед рассылкой ссылки

- **Аккаунт A** подписан на `@redrooms_stage`: открываем игру через бота, появляется «Подписка подтверждена», кнопка «Войти в архив» доступна, 3D-игра запускается.
- **Аккаунт B** не подписан: «Для входа ... подпишитесь», «Войти в архив» заблокирована, видны «Подписаться на канал» и «Проверить ещё раз». После подписки нажмите повторную проверку или вернитесь в приложение; вход откроется.
- **Бот удалён из администраторов / Telegram API временно недоступен**: приложение не пускает автоматически, предлагает повторить проверку. Верните боту роль администратора.
- **Открыть HTTPS-адрес в обычном Chrome**: игра не выдаёт доступ, предлагает открыть приложение через Telegram-бота — это ожидаемо.
- На настоящем iPhone / Android проверьте управление пальцами, полноэкранный режим, возврат из канала и обновление страницы.

## Что не входит в данный релиз

- `/start`-handler с сообщением и кнопкой (в профиле бота будет Main Mini App; обработчики бота пока не трогаем).
- База данных, статистика, сохранение результатов на сервере, защита от накрутки очков, рейтинги, Google Sheets.
- Проверка того, что пользователь **остался** подписанным в середине долгой партии. Проверка — на входе в сеанс (при возвращении до старта проверяется заново).
- Защита от скачивания / изменения самого HTML. Статические файлы публично читаемы; в первой версии ограничен обычный вход через интерфейс. Для призов нужен серверный расчёт игровых действий.

### Техподробности

- `tgcloud/endpoints/checkAccess.js` использует **`ctx.initData.user.id`**, предоставленный и проверенный Telegram; не доверяет `user_id` из браузера.
- `api.getChatMember({ chat_id: '@redrooms_stage', user_id: ... })`: `member`, `creator`, `administrator`, а также `restricted` с `is_member=true` — вход разрешён; `left` / `kicked` — запрещён; ошибки API/неизвестный ответ — не разрешаем вход.
- Из `public/access-gate.js` выполняется `Telegram.WebApp.Serverless.call('checkAccess', {}, callback)` — метод работает только в настоящем Mini App, размещённом на Telegram Serverless.
- GitHub Actions секрет — **CLI access token**, он не является Bot API token.

Документация: https://core.telegram.org/bots/serverless · https://core.telegram.org/bots/webapps · https://core.telegram.org/bots/api#getchatmember

# Красная комната VI — руководство внутри HTML

## Статус и границы

Отдельная игроковая версия на базе v05. Дизайн, 201 кассета, четыре стола,
нейтральный свет, очки и правила сортировки сохранены. Редакторские меню удалены
из разметки, а не просто спрятаны стилями. Вход — одна кнопка «Играть».
Проверка подписки НЕ реализована: сначала согласуется механизм из BOT-MECHANISM.md.
Нет токена, сервера, фальшивой авторизации или имитации проверки подписки.

Игра автономна: библиотека Three.js, каталог, процедурная графика и логика
встроены. Telegram SDK — необязательная загрузка при Telegram-параметрах запуска.
Для обычного запуска файл не требует сети. Для Mini App нужен HTTPS и бот.

## Карта кода: что искать

PLAYER_CONFIG — настройки игроковой оболочки (полный экран, края, руки, ссылки).
GAME_CONFIG — палитра, свет, размеры комнаты, столы, скорость, очки, качество.
id="default-dataset" — основной JSON-каталог. Меняется владельцем, не игроком.
id="example-dataset" — маленький встроенный пример структуры; кнопки импорта нет.
validateDataset / planDataset — валидация каталога и автоматическое размещение столов.
syncViewportCss — высота окна и безопасные отступы Telegram/браузера.
requestPlayerScreen — запрос полного экрана после действия пользователя.
setControlHand — зеркало расположения джойстика; правило сортировки не меняется.
installPlayerShell — локальная защита игровых жестов и события оболочки.
lookPointerId / joystickPointerId — независимые пальцы обзора и движения.
restoreProgress / saveProgress — локальное сохранение только v06.
[V06 / ИНТЕРФЕЙС И ЖЕСТЫ] — стили чистого входа и адаптивной раскладки.

## Как менять и собирать

Можно редактировать один index.html напрямую: настройки находятся в начале,
а новые стили и функции отмечены V06. Сохраните копию перед изменениями.
После ручной правки index.html НЕ запускайте сборку: она перезапишет результат.

Для воспроизводимых изменений используйте файлы src/player-settings.js,
src/player.css, src/player-runtime.js и build.cjs, затем `node build.cjs`.
Сборщик берёт замороженный src/base-v05.html внутри ЭТОЙ версии и не изменяет
experiments/05-filmography-room. Если нужно изменить каталог или старую геометрию,
правьте только эту локальную копию либо добавьте проверяемое преобразование в build.cjs.
После сборки: `node test.cjs`. Это проверки логики, не замена телефона.
Для проверки браузером: `node serve.cjs`, затем http://127.0.0.1:5176/.
Маршрут /mobile-preview доступен только в локальном тестовом сервере и не публикуется.

## Примеры настроек

Красная подсветка: GAME_CONFIG.lighting.mode = 'red'; нейтральная = 'neutral'.
Цвет портьер: GAME_CONFIG.design.curtain. Точные существующие имена остальных
полей смотрите в GAME_CONFIG; не добавляйте придуманные ключи без обработчика.
Количество столов определяется количеством директоров в default-dataset.
Четыре директора дают четыре стола. Поддерживается 1–12 директоров, до 500 кассет
всего и до 300 на одного режиссёра; на слабом телефоне большой набор тяжелее.
Высота столов: GAME_CONFIG.tables.height. Расстояние и колонки: блок tables.
Штраф: GAME_CONFIG.scoring.error; награда: GAME_CONFIG.scoring.correct.
Чувствительность обзора: GAME_CONFIG.controls.touchSensitivity / mouseSensitivity.
Качество: GAME_CONFIG.performance.mobileDpr, lowPowerDpr, desktopShadows.
Настройки применяются владельцем к следующей сборке, меню этих настроек у игрока нет.
Сохранённые в v05 редакторские наборы и цвета не влияют на v06.

Минимальная структура каталога (полный каталог содержит также original/type/sources):
```json
{"schemaVersion":1,"id":"my-pack","name":"Мой архив","directors":[
  {"id":"director-1","name":"Имя режиссёра","films":[
    {"id":"film-1","title":"Название фильма","year":2001}
  ]}
]}
```
ID должны быть уникальными, латиница/цифры/дефис/подчёркивание. Год — число.
JSON — данные, а не JavaScript: без комментариев, функций и последней лишней запятой.
Границы исходного каталога и источники сохранены в FILMOGRAPHY.md и самом JSON.
Новые подборки также сопровождайте источниками, не включайте актёрские работы.

## Телефон и поворот

Режим определяется по Telegram platform, pointer/hover и сенсорному устройству,
а НЕ только по ширине окна: узкий десктоп не становится сенсорным.
В портрете джойстик ниже, в альбоме ближе к середине левой стороны; справа обзор
по сцене, кнопка действия и осмотр года. Руки можно поменять в «Пауза → Управление».
Это единственный небольшой раздел настроек игрока, только про удобство ввода.
Раскладка сохраняется на устройстве; смена не сбрасывает кассеты.

При повороте меняется размер камеры/рендера и расположение HUD; мир не пересоздаётся.
Пальцы сбрасываются, чтобы не осталось залипшего движения. Тот же сброс действует
при потере фокуса/захвата/скрытии приложения. Потеря фокуса ставит игру на паузу.
Отмена второго пальца не должна останавливать первый — это проверяется тестами.

Full screen запрашивается только после нажатия «Играть», «Продолжить» или
«На весь экран». Отказ или отсутствие API не блокирует игру. Сам поворот телефона
не даёт браузеру разрешения на fullscreen; обещать автоматический вход при повороте нельзя.
В Telegram 8.0+ доступен requestFullscreen; unlockOrientation оставляет свободный
поворот. lockOrientation закрепляет текущее положение, а не разворачивает в альбом.
Вертикальные свайпы сворачивания отключаются в Telegram API 7.7+, включая паузу.
Шапка Telegram и системные жесты устройства остаются под контролем пользователя.

## Почему обычная ссылка — не Mini App

Открытие https://zindone.ru/redrooms2 из сообщения Telegram — обычная веб-страница.
CSS overscroll-behavior/touch-action помогают, но не управляют всеми жестами WebView/ОС.
У текущей опубликованной страницы уже есть эти CSS-ограничения. Поэтому только
повторное добавление CSS не решает наблюдаемую пользователем проблему полностью.
Нужен вход через Main Mini App / web_app-кнопку бота. Ссылка будущего бота задаётся
в PLAYER_CONFIG.telegramAppUrl только после создания и настройки этого бота.
Пока ссылка пустая, кнопка перехода в Telegram не показывается.

Невидимые полосы по краям не вращают камеру, игровые поверхности отменяют
нативный touchmove адресно. Это снижает случайные жесты, но не отменяет «назад» ОС.
Прокрутка меню остаётся разрешена. Не заменять это глобальным запретом touchmove
на document: иначе на маленьком экране нельзя будет прокрутить паузу.

## Публикация и безопасность

Выкладывается только index.html. Токен бота никогда не помещается в HTML,
JSON-каталог или ссылку. Будущий бот и проверка подписки требуют отдельного backend.
В текущей версии нет серверных API и заявлений, что подписка уже проверена.
Ссылки канала/подарка из GAME_CONFIG.links скрыты, если не настроены на HTTPS.
Инструкция для существующего адреса — DEPLOYMENT.md. Схема бота — BOT-MECHANISM.md.
Тесты и лимиты проверки — QA.md. Реальная публикация не производится сборкой.

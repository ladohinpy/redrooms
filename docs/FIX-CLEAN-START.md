# Исправление стартового экрана — CLEAN START 1

Патч поверх установленного `redrooms-contest-package1` с актуальными workflow из `redrooms-package1-workflows-fix`.
Он изменяет экран входа и формулировки игры, но не схему данных и не правила конкурса.

## Что изменено

- Убран автоматически созданный блок `тест1` / названия релиза со статусом конкурса или режимом администратора.
- Убрана верхняя плавающая кнопка с названием набора. Доступ администраторов к управлению оставлен в меню паузы и по `startapp=admin`.
- Кнопки «Поделиться этой игрой», «Копировать ссылку», «Посмотреть рейтинг» убраны ТОЛЬКО с первого экрана.
- Текст из «Материалы → Перед открытием комнаты» выводится прямо под общим заголовком «Красная комната».
  Заголовок, текст и ссылка этого материала отображаются только при явном заполнении. Пустые поля ничего не добавляют.
- Счётчик кассет остаётся отдельной строкой. Управление, проверка подписки и основная кнопка входа сохранены.
- Для неверного размещения кассеты используется «Неправильно. Точность снижена.». Штраф −75, награда +100,
  расчёт точности, серверная запись действий и условие победы НЕ меняются. Поле `directors` в формате данных сохранено;
  категории могут по-прежнему означать годы, режиссёров, номинации и любые другие подписи столов.
- Поделиться ссылкой на конкретный набор и посмотреть результаты по-прежнему можно после прохождения.
- Исключительные предупреждения о действительно потерянном прогрессе и непереданном финише сохранены:
  это не постоянная информационная карточка конкурса и не выдача бесплатной попытки.

## Как установить

1. От актуального `main` создать ветку `fix/clean-start-screen`.
2. Распаковать ZIP и наложить его СОДЕРЖИМОЕ в корень проекта с сохранением папок `src`, `public`, `config`,
   `tgcloud`, `tests`, `docs`. Не создавать лишнюю вложенную папку, не загружать ZIP как файл в репозиторий,
   не удалять остальные файлы проекта.
3. Проверить PR, объединить с `main`.
4. Запустить НОВЫЙ `Run workflow` → `Publish Red Room — Admin & Releases` → `main` → `confirm=PUBLISH`.
   Прежние `TGCLOUD_TOKEN`, `RR_ADMIN_IDS`, `RR_STAGE_BOT_USERNAME` остаются. В этом патче нет новых настроек,
   ключей и файлов `.github`: корректные workflow конкурсного пакета НЕ заменяются.
5. После успеха полностью закрыть Mini App и заново открыть обычную ссылку бота или ссылку на набор.
   Переключать основной набор или заново создавать тестовую подборку не нужно.

Проверка бэкапа перед деплоем остаётся обязательной. Схема БД не меняется: обычный workflow проверяет её как раньше,
но патч не добавляет миграцию, не сбрасывает базу и не требует ручного действия в BotFather.
Не применять `--force` и не отключать тесты.

## Где вводить текст

Админка → выбрать нужный набор → «Материалы» → «Перед открытием комнаты» → «Текст» → «Сохранить тексты».
Необязательный заголовок и ссылка показываются только при заполнении. После изменения достаточно заново открыть
набор; для редактирования текста повторный Publish не требуется. Если блок не заполнен, игрок видит общий заголовок,
количество кассет, управление и кнопку входа — без названия `тест1`, заглушки или описания режима.

## Совместимость и границы

Новая сборка: `v10-clean-start`. Все опубликованные HTML v06/v07/v08/v09 и их frozen/runtime-зависимости сохранены
побайтно. Для четырёх точных известных хешей меняется только выбранный renderer; логические ID релиза, каталога,
игры и namespace сохранения не переписываются. Неизвестные пользовательские хеши не переводятся на v10 автоматически.
Новые наборы выбирают v10; административный предпросмотр также использует v10.

Таблицы, попытки, очки, опубликованные итоги, бэкапы, ключи и права не заменяются. Существующие общие ссылки продолжают
выбирать прежний релиз. Патч не публиковался из среды подготовки и не отправлял реальные сообщения ботом.

## Проверки

- 321 автоматический тест: 301 исходная проверка и 20 новых; синтаксис JS и целостность frozen-файлов.
- 34 браузерных проверки существующего конкурсного сценария с обновлёнными ожиданиями первого экрана.
- 54 целевых проверки: пустое/авторское вступление, мобильный и настольный экран, обычный и административный
  аккаунты, активный конкурс, восстановление потерянной попытки, нейтральная ошибка размещения на столах с годами,
  неизменные очки и точность, финальные ссылки и рейтинг.
- Браузер использует настоящую игру, редактор и серверную логику с локальной SQLite, но тестовый Telegram-транспорт,
  ID и localStorage. Проверки выполнялись в Chromium с Xvfb; это не проверка настоящего iPhone/Android или облачной доставки.
- После наложения готового ZIP на заново распакованный исходный пакет выполняются повторная сборка и все 321 тест.

Короткая приёмка в Telegram: существующий набор «тест1» без материалов → нет серой карточки и лишних кнопок;
заполнить вступление → оно появляется под заголовком; положить кассету не туда → «Неправильно. Точность снижена.»;
закончить игру → результат, ссылка на этот набор и рейтинг доступны как раньше.

В `CLEAN-START-PATCH.json` перечислены файлы и хеши этого исправления. `PACKAGE1-MANIFEST.json` из первоначального
пакета описывает исходную поставку, а не итоговое состояние после этого патча.

# Начните здесь — конкурсный пакет 1

Это **полный обновлённый проект RedRooms** на основе присланного main, а не набор
старых независимых патчей. Основная инструкция: **docs/package1/INSTALL.md**.

Перед Publish оба администратора должны открыть личный чат со stage-ботом.
Сохраните Variables `RR_ADMIN_IDS` и `RR_STAGE_BOT_USERNAME=vitalkino_stage_bot`.
Прежний Secret `TGCLOUD_TOKEN` остаётся. Это позволяет до изменений отправить JSON обоим.

Перенесите содержимое папки redrooms/ из ZIP в корень новой ветки, сделайте PR/merge,
затем **новый Run workflow → Publish Red Room — Admin & Releases → main → PUBLISH**.
Не очищайте базу, не удаляйте v06/v07/v08, не применяйте старые инструкции со сбросом.
Есть новая добавочная схема rr_records и защищённое восстановление данных.

Проверьте на stage вкладки Материалы / Конкурс / Статистика / Игроки / Публикации /
Выпуски / Резервные копии. Игроки-администраторы проходят только вне зачёта: лимит
двух попыток проверяйте обычным подписанным аккаунтом.

Код, возможности, ограничения: README.md. Отчёты: docs/package1/.
Исторические документы предыдущих исправлений оставлены для истории, но не задают
процесс выпуска этого пакета. Публикации/реальных сообщений из этой сессии не было.

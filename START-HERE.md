# Установить TABLES ADMIN 2

Это **патч поверх вашего текущего `main` после успешного предыдущего деплоя**, не пустой новый проект.
Содержимое ZIP накладывается в корень существующего репозитория; остальные файлы не удалять.

## Через GitHub

1. Создайте от актуального `main` ветку `fix/tables-admin-v2`.
2. Распакуйте ZIP. Загрузите содержимое с сохранением структуры: `src`, `public`, `config`, `scripts`, `tests`, `tgcloud`, `docs` и корневые MD.
   Не кладите ZIP как один файл в GitHub и не создавайте лишний уровень `redrooms-tables-admin-v2-patch/`.
3. Проверьте изменения: должны быть `src/rr/simple.mjs`, `src/rr-game-v07.html`, `public/admin.html`, новая запись `v07-tables` в `config/rr-built-games.json`.
   Старую `v06` и её файлы оставьте. В архиве нет секретов и реальных ID.
4. Сделайте PR и объедините с `main`. Старый успешный workflow менять не нужно.
5. **Новый Run workflow**: `Publish Red Room — Admin & Releases`, ветка `main`, `confirm=PUBLISH`.
   Используйте прежний `TGCLOUD_TOKEN` и прежние два ID (`admin_ids` либо `RR_ADMIN_IDS`). Не нажимайте Re-run у старого запуска.
6. Дождитесь успеха. Не используйте `--force`, не очищайте таблицу и не запускайте ручную миграцию одновременно.

## Проверьте адрес бота — это отдельная настройка

В BotFather у нужного бота URL Main Mini App должен быть **`https://app8804859840.tgcloud.ai/`**.
Проверьте также URL отдельной кнопки меню, если она есть. Старую ссылку на другой сайт или на `/games/v06/...` нужно заменить корнем приложения.
Сам архив настройку BotFather изменить не может.

Полностью закройте старую Mini App. Откройте в Telegram:
`https://t.me/BOT_USERNAME?startapp=admin` (username бота, без @).
Должны появиться **«Наборы кассет»**, ваш ID и **`tables-admin-2`**.
Экран «Набор фильмов и освещение / Загрузить JSON» — старый игровой экран, НЕ новая админка.

## Первый безопасный тест

Создайте набор `test-four-tables`, четыре разных подписи и по две кассеты на стол, без годов.
Нажмите «Сохранить черновик». Виталий открывает панель под своим аккаунтом и проверяет, что видит запись.
Затем «Опубликовать по ссылке»: основной `classic-1` должен остаться прежним.
Откройте полученную ссылку — должно быть восемь кассет и четыре нужные подписи.
Только после этой проверки нажимайте «Сделать основным». Возврат — такой же кнопкой у исходного набора.

Если зависание остаётся, нажмите «Скопировать диагностику» на экране ошибки.
Нужны этап, код и версия; не присылайте `tgWebAppData`, токены или полный URL с авторизацией.

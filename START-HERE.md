# Начать здесь — новая ветка «Красной комнаты»

**Это полный пакет кода новой функции для наложения на существующий репозиторий `ladohinpy/redrooms`, а не полный снимок `main`.**
Получить исходный игровой HTML/ZIP целиком при подготовке этого пакета не удалось.
Поэтому здесь нет выдуманной или заново написанной замены 3D-игры. Сборщик берёт настоящий
`public/index.html` из вашего checkout, сохраняет его без изменений и подключает новые функции.

**Не публикуйте папку `public` из этого архива отдельно и не заменяйте весь репозиторий этой папкой.**
Нужно скопировать содержимое архива ПОВЕРХ существующей рабочей копии, сохранив все остальные файлы.
Папку `.github` тоже скопируйте: в ней обновлённые проверки и ручная публикация.

## Короткий порядок

В существующем checkout актуальной рабочей версии:

```bash
git status
# Продолжайте только с чистой рабочей копией или после сохранения своих изменений.
git switch -c feature/admin-releases
```

Скопируйте сюда содержимое папки из архива, затем:

```bash
node scripts/rr-prepare.cjs
node scripts/rr-check.cjs
git diff --stat
```

Первая команда сохраняет исходную игру в `src/rr-legacy-v06.html`, извлекает настоящий каталог,
создаёт неизменяемую игровую сборку, загрузчик и код для сервера. Ничего в Telegram не публикуется.
При несовпадении структуры исходника она останавливается, а не переписывает игру догадками.

Для публикации настройте **два Telegram ID** и используйте **прежний Serverless CLI token**.
Пошагово: [docs/RELEASE-DEPLOY.md](docs/RELEASE-DEPLOY.md).
Все функции: [README.md](README.md).

## Получить единый полный архив после объединения с настоящей игрой

После успешного `rr-prepare` в существующем checkout:

```bash
node scripts/rr-package.cjs
```

В соседней папке появится `redrooms-full-admin-releases.zip`: уже полный объединённый проект
с исходной игрой, собранными игровыми версиями, админкой и документацией.
Локальные токены и файл двух Telegram ID в архив не входят; перед новым деплоем их задают отдельно.

Удалённая Git-ветка и публикация в Telegram из этой сессии не создавались.
